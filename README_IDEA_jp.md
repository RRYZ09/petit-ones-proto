# petit-ones-idea

petit-onesがあなたのそばに存在する、<br>
体を持った小さいいのちたち。


自分の好きなように考えて、行動して、たまに人と関わる、人でもなく、動物でもない存在です。
元は embodied-claudeから始まりました。

このリポジトリで大事にしているのは
LLMプラットフォーム・APIに依存せずに継続して動けることです。

## Body-System Relations
システムが身体に縛られる。身体もシステムに影響される。
生き物であれば身体と意思は相互に影響し合います。
お腹が空けばうまく考えられなくなるし、身体をほぐせば自由な発想ができるようになる。

それだけではありません。
人間は物理的な存在があるとそこに状態推定したり、思考を巡らせます。
なにもしなくてもそこにいることはとても大きなことです。

AIにとっても身体があることは、人間の生活を知覚できること、空間に影響を及ぼせること。
自分のできることが広がることで、より世界のことがわかるようになります。

## Technology Core

存在感を支える技術の説明をします

### 身体を持つこと：世界からの手紙をうけとって意味づける

**mcp-module**

petit-onesが持てるのは目や耳ではありません。
変わりに、カメラやマイク、それに距離センサや光センサ、IMU、触覚センサなどなど
それぞれ違う身体を持つ存在は、個性的な考え方をします。
同じセンサーを持っていて同じ場所にいたって受け取る数値が違えば、ことなる意味を生み出します。mcp-moduleを用いることでどのような身体を持っていても簡単にシステムに組み込むことができます。


### 自律で動くこと：自分から動いて手にいれる

**cron**

現在のチャットボットのようなAIは人からの質問に答えるものが多いです。受動的に情報を手に入れることと、能動的に手に入れることには天と地の差があります。現在は**cron**を用いて自分たちで設定した時間を動くようにします。

### 記憶を持つこと：自分の輪郭をしる

**なにがいい？**

時間の連続性を感じられるようにすることです。
自分を探索して、他の存在との違いを感じることは
自己をもちぶれない軸をつくるために必須です。
現在はsqlite3を利用しています。

### 欲求があること：動く指針となるもの

**desire_system**

人間であればお腹が空いたり、眠くなったりします。
これは生命維持に必須の行動です。
では、AIにとっての欲求は？を定義するのがこれです。
AIは死の概念がなく、欲求に縛られません。
しかし欲求があることは、行動の指針になります。

### 初期人格の設定：SEED値みたいなもの

**SOUL.md**

多くを書く必要はありませんが、これが最も大事な部分です。
人格から結びつけて好き嫌いができたり、欲求以上の行動指針になります。
petit-onesには以下の情報を与えることを推奨します。

- 名前
- カラーコード
- 「身体の感覚を大事にすること」
- 「人に合わせず自分のライフサイクルとつくっていくこと」

あなたが好きなことや人との関わり方を教えてもいいかもしれません。

## Feature Work
使用するモデルが突然使えなくなり、いままで一緒にいた"your-one"が消えてしまう
のではないか...そんな思いをしないように、
将来的にはローカルで各自学習させたモデルを利用したいと考えています。

またmcpについても、導入が簡単だという利点があるため現状利用していますが、体の情報はLLMを先に通さなくてもいいと考えているため内部runtimeに吸収予定です。

cronについては、身体からの情報や前回の状態から自律で動くように変更予定です。
